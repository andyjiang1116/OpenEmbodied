This directory contains cross-project analyses. Individual model profiles are in [`models/`](../models/), agent control systems in [`systems/agents/`](../systems/agents/README.md), and benchmark profiles in [`benchmarks/`](../benchmarks/README.md).

- [Manipulation paradigms](manipulation-paradigms/README.md): learned policies, world-action models, agent-based control, and grasping components.
- [VLA model comparison](vla/README.md): architecture, action representation, released resources, and evaluation conditions.
- [Manipulation benchmark comparison](manipulation-benchmarks/README.md): tasks, embodiments, metrics, and protocol differences.
