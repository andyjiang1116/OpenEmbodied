# 机器人操作评测基准对比

> 对比六项机器人操作评测基准的任务设计、能力覆盖与实验协议。

[English](README.md) · [基准对比](benchmark-matrix_ZH.md) · [评测协议](protocol-guide_ZH.md) · [参考资料](references_ZH.md)

## 概览

机器人操作评测基准的任务定义并不相同。它们在目标能力、机器人平台、仿真器、示教数据、观测与动作接口及指标汇总方式上存在差异。因此，跨基准的成功率不能直接作为模型排序依据。

以下六项评测基准覆盖不同的研究问题：

- [LIBERO](../../benchmarks/libero_ZH.md) 研究语言条件桌面操作中的终身学习与多任务知识迁移。
- [CALVIN](../../benchmarks/calvin_ZH.md) 评估策略在连续语言指令下完成长程任务的能力。
- [SimplerEnv](../../benchmarks/simplerenv_ZH.md) 检验仿真评测与真机策略排序的一致性。
- [RoboTwin 2.0](../../benchmarks/robotwin-2_ZH.md) 结合专家数据生成与域随机化条件下的双臂操作评测。
- [RoboDojo](../../benchmarks/robodojo_ZH.md) 在仿真和标准化真机条件下分维度评估通用操作策略。
- [RoboDyna](../../benchmarks/robodyna_ZH.md) 在环境持续演化的动态场景中评估物理推理与动作时效性。

基准选择取决于研究问题；不同基准的分数不构成统一性能排名。

## 六项评测基准的研究目标

| 基准 | 主要回答的问题 |
| --- | --- |
| LIBERO | 从早期任务中学到的知识，能否迁移到后续操作任务？ |
| CALVIN | 策略能否理解语言，并连续完成多个相互依赖的任务？ |
| SimplerEnv | 仿真评测能否反映对应真实机器人上的策略相对表现？ |
| RoboTwin 2.0 | 双臂策略能否适应不同任务、物体、场景和视觉变化？ |
| RoboDojo | 通用策略在泛化、记忆、精细操作、长时程和开放指令方面表现如何？ |
| RoboDyna | 策略能否理解物理动态，并在推理期间持续演化的环境中及时行动？ |

## 各自的侧重点

### 🧠 LIBERO：跨任务知识迁移

LIBERO 面向终身机器人学习设计。不同套件分别改变空间关系、物体、目标和任务规模，适合研究前向迁移、知识保持、多任务学习和任务顺序的影响。它也经常作为模仿学习测试集使用，但普通成功率并不等于完整的持续学习实验；只有学习协议同时衡量迁移与遗忘时，才能支持相应结论。

### 🔗 CALVIN：语言条件长时程控制

CALVIN 在桌面环境中设置 Franka 机器人、34 个原子任务及对应语言标注。标准评测使用五条指令组成的任务链，统计策略连续完成的平均任务数，以及完成各序列长度的成功率。该协议呈现长程执行中的误差累积与任务切换能力。

### 🌉 SimplerEnv：仿真对真机的预测能力

SimplerEnv 在仿真中重建对应的真实机器人评测场景，检验仿真结果能否反映真机中的策略表现与相对排序。结果需说明环境变体、机器人平台、视觉匹配或多变体汇总方式、策略权重，以及对应的真机协议。

### 🦾 RoboTwin 2.0：可扩展双臂操作与鲁棒性

RoboTwin 2.0 提供专家数据生成流程和约 50 项双臂操作任务。其物体资源、任务程序、多种机器人形态与域随机化设置覆盖数据生成、双臂协作和环境鲁棒性研究。基础场景与随机化场景应分别报告结果。

### 🥋 RoboDojo：仿真—真机综合能力评测

RoboDojo 的仿真部分包含 42 个任务，覆盖泛化、记忆、精细操作、长时程执行和开放词汇指令五个能力维度；真机部分包含三个双臂机器人形态上的 18 个任务。策略通过 XPolicyLab 统一接入。RoboDojo 以评测为核心，基准任务、场景布局、计分方式和结果产物与策略实现相互分离。

### ⏱️ RoboDyna：动态物理过程与推理延迟

RoboDyna 在受到重力、摩擦、碰撞、接触与状态变化影响的场景中评估语言条件双臂策略。成对的同步与异步协议使用相同随机种子，区别在于策略推理期间环境是否继续演化。20 项概念任务分别考察五类物理能力；10 项家庭场景任务则在更复杂的视觉与语义环境中评估这些能力。推理延迟因此直接影响异步协议的任务结果。

## 研究问题与评测范围

- **持续学习与多任务迁移：** LIBERO；需同时记录任务套件和学习顺序。
- **长程指令执行：** CALVIN；需报告完整的五指令序列结果。
- **仿真对真机表现的预测：** SimplerEnv；需报告配对设置的相关性或排序一致性。
- **双臂数据生成与鲁棒性：** RoboTwin 2.0；需区分基础场景与随机化场景。
- **通用策略的分维度能力：** RoboDojo；需同时报告各能力维度和整体结果。
- **动态物理推理与推理延迟：** RoboDyna；需分别报告同步与异步结果。

## 哪些结果可以比较

只有当基准版本、任务划分、观测、动作空间、回合长度、评测次数、随机种子、检查点选择和汇总规则一致时，结果才适合直接横向比较。即使基准名称相同，摄像头视角、本体状态、历史帧长度、语言输入或初始状态分布的变化，也可能实质性改变任务。

不同基准之间应比较能力覆盖范围与实验设计，而不是直接比较成功率百分比。更多细节见[评测协议](protocol-guide_ZH.md)和[基准对比](benchmark-matrix_ZH.md)。
