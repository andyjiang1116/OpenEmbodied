## Repository Structure

```text
models/       Individual model and policy notes
benchmarks/   Individual evaluation-suite notes
datasets/     Dataset notes
simulators/   Simulator and environment notes
robots/       Robot platform and embodiment notes
docs/         Cross-cutting topics, reproductions, and shared assets
```

Entity directories use stable, lowercase slugs and keep one primary page per entity. Documents link to those pages instead of duplicating the same facts, so a source update can be maintained in one place.
