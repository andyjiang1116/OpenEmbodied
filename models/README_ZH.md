> 按模型在具身智能系统中的功能组织技术档案。

[English](README.md)

## 模型家族

### 🧠 [Vision-Language-Action Models](vla/README_ZH.md)

将视觉观测与语言指令映射为机器人动作的策略模型。目前收录 OpenVLA、SmolVLA、π0 / π0-FAST / π0.5 和 NVIDIA Isaac GR00T N1.7。

### ✋ [Grasping Models](grasping/README_ZH.md)

覆盖平行夹爪的抓取检测、灵巧手的抓取姿态生成及执行。目前收录 AnyGrasp、UniDexGrasp、DexGraspNet 2.0 和 DexGrasp Anything。

每篇档案分别说明研究目标、模型输入输出、方法设计、已发布资源、评测设置与系统集成条件。涉及性能的结论均附有参考资料。
