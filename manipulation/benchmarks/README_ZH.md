## 各评测基准测量什么

**LIBERO** 研究语言条件桌面任务间的知识迁移。Spatial、Object 和 Goal 套件分别控制不同变化；在原始 LIBERO-100 持续学习协议中，LIBERO-90 与 LIBERO-10 承担不同作用。固定策略的最终平均成功率与顺序学习中的遗忘、前向迁移不是同一指标。

**CALVIN** 衡量 Franka 机器人在持续变化的同一场景中，能够连续完成多少条相互依赖的语言指令。五步指令曲线可以揭示误差累积：首项成功不代表后续任务仍可完成。结果应报告 success-at-1 至 success-at-5 及平均完成长度。

**SimplerEnv** 检验 Google Robot 或 WidowX 等策略的仿真结果能否反映相应真机评测。单独的仿真成功率不足以说明这种一致性；策略排序与相关性需要配对真机数据。视觉匹配还是环境变体汇总，也属于评测协议的一部分。

**RoboTwin 2.0** 连接任务构建、专家示教生成、策略训练和双臂评测。标准场景与随机化场景考察不同条件；结果需标明机器人形态、任务配置、训练示教、随机化设置和场景种子。

**RoboDojo** 从泛化、记忆、精细控制、长程执行和开放指令五个维度评估通用操作策略。仿真与标准化真机评测是不同路径。策略通过 XPolicyLab 接入，综合分数应结合各能力维度解读。

**RoboDyna** 研究持续演化场景中的动态物理推理。同步与异步协议的区别在于模型推理期间环境是否继续变化。成功率和进度指标应按能力类别、难度条件及计时模式分别报告。

## 如何阅读评测结果

比较两个策略前，应记录基准版本、任务划分、机器人与仿真器、训练数据、观测和动作接口、checkpoint、执行步数、重置方式、回合数、随机种子及成功判据。还需说明模型推理期间环境是否继续运行。这些条件中任一项变化，都可能在策略架构不变的情况下改变分数。不同基准的任务和统计分母不同，不能直接用各自分数排名。
