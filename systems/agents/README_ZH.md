# Agent 式具身操作

[English](README.md) · [具身系统](../README_ZH.md) · [具身操作技术范式](../../analysis/manipulation-paradigms/README_ZH.md)

Agent 式具身操作将多模态模型置于闭环执行系统中。模型可以选择机器人指令、审查另一策略的动作建议，或决定何时调用已学习的技能。控制器与工具接口将决策转换为受约束的物理动作，并返回新观测供下一轮决策使用。

| 控制方式 | 代表工作 | Agent 的作用 |
| --- | --- | --- |
| 直接与混合动作控制 | [GPT-6 Astra as an Embodied Policy](gpt-as-policy_ZH.md) | 直接生成末端执行器目标，或审查并修正 π0.5 的候选动作 |
| 按需介入 | [π0.5 + Astra 按需介入](pi05-call-astra_ZH.md) | 学习型触发器检测到恢复需求时接管控制 |
| 上下文机器人学习 | [GPT-Policy](gpt-policy_ZH.md) | 利用示教与执行历史提出受约束的机器人工具动作 |

这些方法的区别在于控制接口，而非所用基础模型的名称。评测应说明各组件的动作权限、观测频率、推理延迟、控制器约束、机器人形态，以及推理期间物理时间是否继续流逝。
