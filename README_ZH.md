## 关于 OpenEmbodied

具身智能研究如何让智能体在真实物理世界中完成感知、推理与行动。OpenEmbodied 是一个由社区共同建设的开放知识库，致力于降低这一快速发展领域的学习、研究与实践门槛。

本项目将系统整理高质量论文、模型、数据集、评测基准、开发工具与实践笔记。每项内容应说明它解决的问题、核心思路、实验证据与适用边界，而不只是增加一条链接。

> [!NOTE]
> OpenEmbodied 目前处于建设初期，仓库结构与精选内容将持续完善。

## 你将在这里找到

- **前沿研究**：值得关注的论文、模型、数据集、评测基准与开源项目。
- **基础知识**：理解具身智能所需的机器人学、学习、感知与控制知识。
- **实践资源**：仿真环境、开发工具、学习教程与复现记录。
- **结构化解读**：对贡献、假设、实验结果与局限的简明梳理。

## 知识地图

| 方向 | 主题 |
| --- | --- |
| 视觉—语言—动作模型 | 多模态对齐、动作表示、通用机器人策略 |
| 机器人操作 | 抓取、灵巧操作、双臂协作 |
| 具身导航 | 空间推理、建图、探索与目标导航 |
| 运动与全身控制 | 腿式机器人、人形机器人、移动操作 |
| 世界模型与规划 | 动力学建模、预测控制、长时程推理 |
| 具身学习 | 模仿学习、强化学习、迁移与泛化 |
| 数据与评测 | 机器人数据集、仿真环境、基准与评测协议 |

## 学习路径

```text
数学与机器学习
      ↓
机器人学、感知与控制
      ↓
多模态学习与具身学习
      ↓
系统实现、实验与评测
```

1. 学习坐标变换、运动学、概率、优化与反馈控制。
2. 掌握三维感知、状态估计、深度学习与序列建模的基础。
3. 了解模仿学习、强化学习、视觉语言模型与动作表示。
4. 先在仿真环境中完成复现，再逐步进入真实机器人系统。

## 收录原则

- 优先引用原始论文、官方项目页、代码与数据集。
- 记录公开时间，并明确区分预印本与正式发表版本。
- 说明资源的价值及其结论适用范围。
- 区分作者结论、社区理解与独立复现结果。
- 保持描述简洁、可验证，并兼顾初学者与实践者。

## 参与贡献

欢迎参与 OpenEmbodied。你可以通过 Issue 推荐资源、提出改进建议或报告错误，也可以通过 Pull Request 增加内容或完善已有说明。

推荐资源时，请提供官方链接、所属方向、简短客观的介绍、收录理由，以及适用时的公开或发表时间。
